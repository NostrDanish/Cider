# Improvement Deep-Dive — Cider — 2026-10-21

## Top recommendations (ranked, with effort S/M/L)
1. **Pin the git-URL dependencies to commit SHAs**: `electron` (`git+https://github.com/castlabs/electron-releases.git`) and `mdns-js` (`git+https://github.com/ciderapp/node-mdns-js.git`) resolve to whatever the branch tip is at install time — a compromised or force-pushed upstream silently ships in builds. Pin SHAs (or use the versioned castlabs tarballs; the build config already pins `16.0.7+wvcus` — make the npm dep match). [S]
2. **Decide the fork's Electron strategy**: Electron 16 is years EOL; the stalled `feature/electron19` branch shows the pain. The Widevine constraint (castlabs builds) is real, but castlabs publishes far newer wvcus releases — either schedule a tracked upgrade (electron-builder ^22 → current, typescript ^4.6 → 5.x, react 17 → 18/19 alongside) or document 'frozen at 16 for Widevine' in README so contributors stop trying piecemeal bumps. [L upgrade, S doc]
3. **Known-vuln floor bumps**: `adm-zip 0.4.10` (pre-0.4.11 has a path-traversal fix), `express ^4.17.3` → ^4.21, `ws ^8.5` → ^8.18, `electron-updater ^4.6.5` → ^6. All minor-line, low-risk. [S]
4. **One CI system, not two**: `.circleci/` AND `.github/` both exist — pick one (GitHub Actions, since the repo lives here) and delete the other; dual CI is config drift by definition. [S]
